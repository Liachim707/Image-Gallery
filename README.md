# Image Gallery

Интерактивная галерея случайных изображений, созданная с помощью HTML, CSS и JavaScript. Проект позволяет просматривать фотографии, выбирать понравившиеся изображения и автоматически переключать их.

## Возможности

- Загрузка четырёх случайных фотографий с помощью API [Lorem Picsum](https://picsum.photos/).
- Просмотр выбранной фотографии в большом формате.
- Отображение имени автора фотографии.
- Подсветка выбранной миниатюры.
- Загрузка нового набора фотографий кнопкой **NEW**.
- Автоматическое переключение изображений каждые 5 секунд.
- Возможность остановить и снова запустить автоматическое переключение кнопкой **STOP / PLAY**.
- Автоматический выбор первой фотографии после загрузки нового набора.

## Структура проекта

- `index.html` — HTML-разметка страницы.
- `index.css` — стили и оформление галереи.
- `index.js` — загрузка изображений, выбор фотографий и управление таймером.
- `package.json` — настройки проекта и команда запуска.

1. Откройте [CodeSandbox](https://codesandbox.io/).
2. Создайте новый проект или импортируйте этот репозиторий с GitHub.
3. Дождитесь установки зависимостей.
4. Запустите проект кнопкой **Run** (если она доступна в выбранном шаблоне).

## Локальный запуск

Для запуска на компьютере необходим установленный [Node.js](https://nodejs.org/).

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/Liachim707/Image-Gallery.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd Image-Gallery
   ```

3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите проект:

   ```bash
   npm start
   ```

5. Откройте адрес, который появится в терминале (обычно это `http://localhost:3000`).

> Для загрузки фотографий требуется подключение к интернету, поскольку изображения и список фотографий запрашиваются с сервиса Lorem Picsum.
