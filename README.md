# Image Gallery

## Описание проекта

Image Gallery - интерактивная галерея случайных изображений, созданная с помощью HTML, CSS и JavaScript. Проект позволяет просматривать фотографии, выбирать понравившиеся изображения и автоматически переключать их.

## Возможности проекта

- Загрузка четырёх случайных фотографий с помощью API [Lorem Picsum](https://picsum.photos/).
- Просмотр выбранной фотографии в большом формате.
- Отображение имени автора фотографии.
- Подсветка выбранной миниатюры.
- Загрузка нового набора фотографий кнопкой **NEW**.
- Автоматическое переключение изображений каждые 5 секунд.
- Возможность остановить и снова запустить автоматическое переключение кнопкой **STOP / PLAY**.
- Автоматический выбор первой фотографии после загрузки нового набора.

## Как запустить проект

### В CodeSandbox

1. Откройте [CodeSandbox](https://codesandbox.io/).
2. Импортируйте репозиторий GitHub.
3. Дождитесь загрузки проекта.
4. Откройте Preview, чтобы просмотреть и проверить приложение.

### Локально на компьютере

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в терминале.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите локальный сервер:

   ```bash
   npm start
   ```

5. Откройте в браузере адрес, указанный в терминале.
